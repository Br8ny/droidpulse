## Reddit — r/Android

**Title:** I built a daily "trending open-source Android apps" leaderboard (no APKs hosted, links to official releases)

**Body:**

> I wanted an easy way to see what open-source Android apps are actually gaining traction right now, so I made droidpulse.
>
> - Pulls metadata from the F-Droid index and star counts from GitHub
> - Ranks 450 apps with an activity-weighted pulse score and groups them by category
> - Refreshes daily with GitHub Actions
> - **Hosts no APKs** — every entry links straight to the developer's latest release page
>
> Live site: https://br8ny.github.io/droidpulse/
>
> The score is a momentum proxy (stars + recent GitHub/F-Droid activity), not an exact star-delta count. Feedback welcome — especially on categories and missing apps.

## Hacker News

**Title:** Show HN: droidpulse – trending open-source Android apps ranked by GitHub momentum

**Body:**

> droidpulse is a daily-generated leaderboard of open-source Android apps.
>
> It joins F-Droid's public index (categories, versions, source URLs) with GitHub star counts, scores apps with an activity-weighted momentum formula, and publishes both a browsable site and a markdown leaderboard.
>
> No APKs are redistributed — each app links to its official GitHub release page.
>
> Site: https://br8ny.github.io/droidpulse/
> Code: https://github.com/Br8ny/droidpulse
>
> Happy to explain the scoring choices or the data limitations.
